# TRADENBOT — гарант-бот для сделок с NFT-подарками

Бот работает как **гарант (эскроу)** между продавцом и покупателем NFT-подарка:

1. Участник создаёт сделку: подарок, сумма, @продавец, @покупатель.
2. Покупатель переводит деньги владельцу бота **@ws3xx3**.
3. Владелец получает сделку в чат и жмёт **«✅ Подтвердить оплату»**.
4. **Продавцу сразу приходит чек об оплате** в чат с ботом.
5. Продавец передаёт подарок → владелец жмёт **«➡️ Завершить сделку»** → оба получают финальный чек.

Владелец/гарант: **@ws3xx3** (единственный, кто может подтверждать оплату).

---

## 1. Получение токена у @BotFather

1. Откройте Telegram и найдите **@BotFather** → нажмите **Start**.
2. Отправьте: `/newbot`
3. На вопрос *«What name would you like to call your bot?»* — ответьте: `TRADENBOT`
4. На вопрос *«What username would you like?»* — придумайте username в формате
   (должен заканчиваться на `bot`, например): `TRADENBOT_ws3xx3_bot`
5. BotFather пришлёт сообщение с токеном вида:
   `123456789:AAH...` — **это и есть ваш токен**, скопируйте его.

> Токен — секрет. Не публикуйте его нигде.

Дополнительно (красивое меню кнопок): у BotFather → `/mybots` → ваш бот →
**Bot Settings → Menu Button** → задайте текст `TRADENBOT`.

## 2. Запуск локально (проверка)

```bash
cd tradenbot
python -m venv venv
venv\Scripts\activate          # Windows (в Linux/macOS: source venv/bin/activate)
pip install -r requirements.txt

# Windows (cmd):
set BOT_TOKEN=ВАШ_ТОКЕН && python bot.py
# PowerShell:
$env:BOT_TOKEN="ВАШ_ТОКЕН"; python bot.py
# Linux/macOS:
export BOT_TOKEN=ВАШ_ТОКЕН && python bot.py
```

Важно: **ваш аккаунт @ws3xx3 должен первым делом нажать `/start` боту** —
только тогда бот сможет слать вам кнопки подтверждения оплаты.

## 3. Бесплатный хостинг (Render, 2 варианта)

### Вариант A — GitHub + Render (рекомендуется)

1. Создайте репозиторий на **github.com** и загрузите папку `tradenbot`
   (файлы `bot.py`, `requirements.txt`, `render.yaml`, `.env` **не** загружайте).
2. Зайдите на **render.com** → **New → Blueprint** → подключите репозиторий.
3. Render подхватит `render.yaml`. В поле **BOT_TOKEN** вставьте токен от BotFather.
4. Нажмите **Apply** — бот запустится.

### Вариант B — Railways

1. **railway.app** → **New Project → Deploy from GitHub repo** (или CLI).
2. В **Variables** добавьте `BOT_TOKEN` = ваш токен.
3. Deploy — бот работает.

### Вариант C — свой VPS (самый надёжный)

На любом дешёвом/бесплатном VPS (Oracle Cloud Always Free, и т.п.):

```bash
git clone <ваш-репозиторий> && cd tradenbot
pip install -r requirements.txt
BOT_TOKEN=ВАШ_ТОКЕН nohup python bot.py > bot.log 2>&1 &
# или через systemd/pm2, чтобы не падал после перезагрузки
```

**Честное предупреждение:** бесплатные хостинги (Render/Railway free)
засыпают при простое и могут удалять данные. Для серьёзной работы с реальными
деньгами используйте VPS — иначе бот может не ответить в нужный момент.
Данные сделок хранятся в файле `data/deals.json` — делайте ему бэкап.

## 4. Как пользоваться ботом

| Кнопка | Что делает |
|---|---|
| 🛒 Новая сделка | Пошаговый мастер создания сделки (4 шага) |
| 📋 Мои сделки | Список ваших сделок со статусами |
| ℹ️ Помощь | Инструкция |
| 👑 Админ-панель | Только для @ws3xx3: статистика и активные сделки |

**Подтверждение оплаты (только владелец):** при создании сделки бот присылает
@ws3xx3 сообщение с кнопками **«✅ Подтвердить оплату»** / **«❌ Отклонить»**.
После подтверждения продавцу мгновенно приходит **чек** в чат с ботом.

---

## 5. Статусы сделок

- 🕐 **Ожидает оплаты** — создана, покупатель ещё не платил
- 💰 **Оплачена** — владелец подтвердил, чек отправлен продавцу
- ✅ **Завершена** — подарок передан, финальный чек всем
- ❌ **Отклонена** — владелец отклонил оплату
